# payflow(mySns) — 기능 구현 요약

## SNS 코어
- 게시물 CRUD (이미지 다중 첨부, 일반/크라우드펀딩 타입)
- 피드 / 게시물 가시성 필터 (공개 · 본인 · 팔로우 기반)
- 좋아요 · 북마크 · 공유, 댓글 + 댓글 좋아요
- 팔로우, 비공개 계정 + 팔로우 요청(승인/거절)
- 게시물 · 사용자 검색 (해시태그 포함)

## 메시징
- 1:1 DM (대화방 + 메시지), 안읽음 카운트
- 게시물 DM 공유, 팔로워 / 팔로잉 목록

## 실시간 / 알림
- SSE 단일 스트림으로 알림 + 메시지 통합 수신 (다중 탭 지원)
- 좋아요/팔로우/댓글 알림 + 도배 방지 스로틀링

## 핀테크
- 지갑 + 거래 원장 (충전 · 출금 · 잔액/예치 분리 관리)
- P2P 송금
- 1/N 정산 (에스크로 예치 → 정산/환불, 퍼센트 배분)
- 크라우드펀딩 (all-or-nothing, 목표 달성 시 정산 / 미달 시 전액 환불, 자동 마감)
- 프리미엄 구독 (자동 갱신 / 해지)

## AI / 미디어
- 영수증 멀티이미지 종합 OCR (추천값 자동 채움, 신뢰도 낮으면 수동입력)
- 영수증 / 사진 업로드 분리
- 2단계 commit 이미지 호스팅 (임시 업로드 → 게시 시 확정)

## 인증 / 보안
- JWT 인증 (Access / Refresh)
- GraphQL 3-layer 인가 (경로 + 메서드 + 데이터 마스킹)
- Admin RBAC + Grafana 어드민 게이트
- 회원가입 검증, 회원 셀프 탈퇴 (금융 가드 포함)

## 운영 / 관측성
- 메트릭(VictoriaMetrics) + 로그(Loki) + Grafana 대시보드
- Golden Signals 대시보드 + 장애 알림 (Discord)
- Docker Compose 배포 (멀티스테이지·멀티아치 빌드, BFF 구조)

# 프론트엔드 (Next.js BFF)

## 인증 / BFF
- Auth.js v5(NextAuth) 토큰 중심 JWT 인증, 로그인 인프라
- Apollo Client로 GraphQL 연동 + Bearer 토큰 자동 첨부
- 회원가입 페이지 + 실시간 검증 + BE 에러 메시지 표면화
- 로그아웃 후 뒤로가기 시 인증 화면 노출 차단

## 피드 / 게시물
- 브랜드 랜딩(네이버페이 그린 디자인 시스템) + /home 피드
- 피드 카드, 이미지 캐러셀, 좋아요/북마크, 작성자 수정·삭제
- 대표 댓글 미리보기 + 무한스크롤 / 페이지네이션
- 게시물 작성: 카카오맵 POI, 사진 blob/OCR, item 모델
- 게시물 상세/모달, 공유 SiteHeader/Footer, /about·/support·/notices

## SNS / 프로필
- 북마크, 비공개 계정 + 팔로우 요청
- 프로필 편집(표시이름·소개·아바타), 햄버거 UserMenu + 프로필/설정 라우트

## 메시징 / 실시간
- 다이렉트 메시지 UI + 하단 탭 네비
- SSE 구독으로 실시간 전환(폴링 제거) — 알림/메시지
- 검색 + 활동 알림

## 핀테크
- 지갑·송금 UI
- 1/N 정산 작성 플로우 통합
- 크라우드펀딩(생성·후원·조기마감·체크리스트·목록)
- 프리미엄 구독 · 이름 강조 · 게시글 테마 · 정산 내역

## 미디어 / 어드민
- 영수증/사진 업로드 분리 + 멀티이미지 영수증 OCR(composer)
- ADMIN 전용 Grafana 플로팅 숏컷 + 어드민 게이트(세션 role 전파)
